# learning-hub

Interactive, phone-first lessons with an AI tutor. Astro + MDX, deployed on Vercel (framework preset **Astro**).

- `npm run dev` / `npm run build` / `npm run check` (SymPy maths checks)
- `src/content/lessons/*.mdx`: lessons; `src/components/`: lesson components
- `public/legacy/`: the 1.0 explainers, served unchanged
- Plan: `research/PLAN-2.0.md`
